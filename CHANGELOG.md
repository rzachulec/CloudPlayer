# Changelog

All notable changes to CloudPlayer are documented here and on the [GitHub Releases](../../releases) page.

Release notes for each versioned release are auto-generated from merged pull requests (configured in [`.github/release.yml`](.github/release.yml)).

## [Unreleased]

- Rolling `nightly` staging pre-releases on pushes to `main` (`install.sh --nightly`)
- Versioned releases via `v*` tags or the **Release** workflow (`workflow_dispatch`)
